# Design docs

Technical design documentation for panopticon. User-facing docs live one level up in
[`../`](..) (e.g. `auth.md`, `macos-setup.md`). Internal planning, roadmap, and backlog
documents are intentionally not tracked in this distributable repository.

- [`ARCHITECTURE.md`](ARCHITECTURE.md) — target design: topology, the determinism invariant,
  and interfaces.
- [`decisions/`](decisions/) — architecture decision records (ADRs).
